# Trash Amp 0.1.0-beta.9

Testing prerelease for Apple Silicon Macs running macOS 15 or newer, and the
first Linux build: a `.deb` for x86-64 with glibc 2.35 or newer, such as
Ubuntu 22.04, Debian 12 and later.

## Linux

- New `.deb` package with a menu entry and icons. Install it with
  `sudo apt install ./trash-amp_0.1.0~beta.9-1_amd64.deb`, which also installs
  the libraries it needs.
- Collector logins are saved through Secret Service (KWallet or GNOME Keyring),
  which must be running and unlocked. Earlier source builds forgot them on quit.
- Tested on Kubuntu with Wayland. Media keys and file dialogs are not yet
  verified on Linux, and closing the window leaves playback running in the
  background ([#13](https://github.com/AberrantWolf/trash-amp/issues/13)).

## Playback

- Local Opus files play, both `.opus` and Opus in `.ogg`.
- Opus from Collector seeks directly instead of decoding from the start of the
  track, and applies the volume adjustment stored in the file.
- The folder refresh banner's buttons stack in narrow windows instead of being
  cut off at larger text sizes.

## Install

### macOS

Download `trash-amp-0.1.0-beta.9-macos-arm64.zip` and its `.sha256` file.
Run the following command from the download directory, then extract the ZIP
and move **Trash Amp.app** into Applications.

```sh
shasum -a 256 -c trash-amp-0.1.0-beta.9-macos-arm64.zip.sha256
```

The release workflow requires Developer ID signing and Apple notarization.

### Linux

Download `trash-amp_0.1.0~beta.9-1_amd64.deb` and its `.sha256` file, then run
from the download directory:

```sh
sha256sum -c 'trash-amp_0.1.0~beta.9-1_amd64.deb.sha256'
sudo apt install './trash-amp_0.1.0~beta.9-1_amd64.deb'
```

## Notes

Separate-Mac first launch, upgrades, and VoiceOver qualification remain open.
Disc playback remains experimental.
[Beta checklist](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.9/docs/release-gates.md).

Local matching includes LGPL-2.1-or-later fingerprint code. The tagged source
and Cargo.lock pin the build inputs.
[Matching and rebuild details](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.9/docs/digital-album-matching.md).

When reporting an issue, include the Trash Amp version, your operating system
and version, music source type and steps to reproduce. Omit credentials and
private server details.
[Report an issue](https://github.com/AberrantWolf/trash-amp/issues).
