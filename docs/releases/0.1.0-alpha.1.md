# Trash Amp 0.1.0-alpha.1

First macOS alpha for testing and feedback. Apple Silicon (arm64), macOS 15 or
newer. Intel Macs, Windows, Linux and iOS are not supported by this package.

## Install

Download `trash-amp-0.1.0-alpha.1-macos-arm64.zip` and its `.sha256` file. Verify
the download in Terminal with `shasum -a 256 -c` followed by the checksum filename.
Extract the ZIP and move **Trash Amp.app** into Applications.

This alpha uses an ad-hoc signature and is not notarized. macOS may block the
first launch. After attempting to open it, use **System Settings → Privacy &
Security → Open Anyway** if you trust this download. Developer ID signing and
notarization remain future release work.

## Included

- Album and artist browsing, search, playback queue and macOS media controls.
- Filesystem music libraries, including mounted network shares. Each folder
  keeps its own cached catalog; reopen it using the saved-folder selector and
  use **Refresh folder** to scan for changes. Cached catalogs can be browsed
  offline; local playback needs the source files.
- Local tags, CUE/BIN and supported all-audio redumper packages, plus optional
  MusicBrainz lookups. Music files remain read-only.
- Junk Collector `v0.1.0-alpha.1` connections, collections, lists and offline
  downloads. Enrollment requires approval on the server. Credentials use the
  macOS Keychain; private certificate trust uses owner-provided trust material.

## Known limits

- This is an early alpha. Network interruptions, device loss, accessibility,
  large-library performance and end-to-end audio fidelity need further testing.
- Scans replace a folder's complete catalog; incremental scans are not yet
  implemented. Failed scans retain the previous catalog.
- WAV, FLAC, MP3, Vorbis and CDDA are the initial playback validation targets.
  Gapless playback has not been qualified through output capture; bit-perfect
  output is not claimed. AAC/M4A gapless playback and Opus are not advertised
  as supported. Multichannel audio requires further work.
- Raw redumper support is limited to single-session, stereo, all-audio discs.
  Raw mixed-mode/multisession discs, hidden first-track audio controls and
  de-emphasis are incomplete. PRE flags are reported but not applied.
- Collector integration passed automated real-server tests; its full native
  network and lifecycle acceptance matrix remains incomplete.
