# Trash Amp 0.1.0-beta.8

Testing prerelease for Apple Silicon Macs running macOS 15 or newer.

## Playback and browsing

- Space pauses or resumes the current track even if Play album still has focus.
  Text fields continue to accept spaces.
- Up and Down select album tracks, and Enter plays the selected track. Short
  windows keep search, albums, tracks, and Up Next reachable.
- Home highlights the action available for the selected source. Narrow layouts
  give Settings labels room to wrap at larger text sizes, and touch transport
  controls have larger hit areas.
- Large catalog refreshes build the search index in the background, and the
  browser creates visible rows on demand.

## Collector

- Search shows cached matches first and keeps server results within the selected
  collection. A late response for an earlier playlist leaves the active selection
  and edit target intact.
- Cancelled and failed downloads release their storage reservations. Settings →
  Downloads shows individual records and lets you clear them or retry unfinished
  downloads.
- Original playback detects Vorbis and Opus in Ogg files served by Collector.
  The playback modes use Junk Collector beta.32. Earlier servers and separate
  media connections can use saved audio when available.
  [Collector connection guide](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.8/docs/collector-connection.md).

## Install

Download `trash-amp-0.1.0-beta.8-macos-arm64.zip` and its `.sha256` file.
Run the following command from the download directory, then extract the ZIP
and move **Trash Amp.app** into Applications.

```sh
shasum -a 256 -c trash-amp-0.1.0-beta.8-macos-arm64.zip.sha256
```

The release workflow requires Developer ID signing and Apple notarization.
Separate-Mac first launch, upgrades, and VoiceOver qualification remain open.
Disc playback remains experimental. The beta assets are for macOS.
[Beta checklist](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.8/docs/release-gates.md).

Local matching includes LGPL-2.1-or-later fingerprint code. The tagged source
and Cargo.lock pin the build inputs.
[Matching and rebuild details](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.8/docs/digital-album-matching.md).

When reporting an issue, include the Trash Amp version, macOS version, music
source type and steps to reproduce. Omit credentials and private server details.
[Report an issue](https://github.com/AberrantWolf/trash-amp/issues).
