# Trash Amp 0.1.0-beta.7

Testing prerelease for Apple Silicon Macs running macOS 15 or newer.

## Collector playback

Choose a playback format under **Settings → Servers**. The preference applies
to Collector connections on this device when Trash Amp opens a track.

- **Original** plays the source audio. Collector serves supported CD tracks as
  seekable WAV.
- **High Bandwidth** is the default. It plays existing FLAC or MP3, reuses
  prepared FLAC when available, and streams live FLAC when needed.
- **Low Bandwidth** streams Opus. The default is 128 kbps, with a configurable
  target from 6 to 256 kbps.

The modes use Junk Collector beta.32's normal authenticated audio connection.
Earlier servers and separate media connections use saved audio when available.
Completed downloads take precedence in all three modes. See the
[Collector connection guide](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.7/docs/collector-connection.md#playback-format).

## Install

Download `trash-amp-0.1.0-beta.7-macos-arm64.zip` and its `.sha256` file.
Run the following command from the download directory, then extract the ZIP
and move **Trash Amp.app** into Applications.

```sh
shasum -a 256 -c trash-amp-0.1.0-beta.7-macos-arm64.zip.sha256
```

The release workflow requires Developer ID signing and Apple notarization.
Separate-Mac first launch and upgrade testing remain open. Disc playback remains
experimental. The beta assets are for macOS. See the
[beta checklist](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.7/docs/release-gates.md).

Local matching includes LGPL-2.1-or-later fingerprint code. The tagged source and
Cargo.lock pin the build inputs. See the
[matching and rebuild details](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.7/docs/digital-album-matching.md).

When reporting an issue, include the Trash Amp version, macOS version, music
source type and steps to reproduce. Omit credentials and private server details.
[Report an issue](https://github.com/AberrantWolf/trash-amp/issues).
