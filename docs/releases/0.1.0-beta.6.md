# Trash Amp 0.1.0-beta.6

Testing prerelease for Apple Silicon Macs running macOS 15 or newer.

## What changed

- Removed **Review matching in Collector** from album details. Trash Amp still
  browses and plays music from Junk Collector, including offline downloads.
- **Find matching albums** remains available for eligible local folder albums.

## Install

Download `trash-amp-0.1.0-beta.6-macos-arm64.zip` and its `.sha256` file. Run the
following command from the download directory, then extract the ZIP and move
**Trash Amp.app** into Applications.

```sh
shasum -a 256 -c trash-amp-0.1.0-beta.6-macos-arm64.zip.sha256
```

The release workflow requires Developer ID signing and Apple notarization.
Separate-Mac first launch and upgrade testing remain open. Disc playback remains
experimental, and the broader Collector interruption and reconnect tests are
still pending. See the [beta checklist](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.6/docs/release-gates.md)
and the [beta.5 notes](https://github.com/AberrantWolf/trash-amp/releases/tag/v0.1.0-beta.5)
for the existing features and qualification limits.

Local matching includes LGPL-2.1-or-later fingerprint code. The tagged source and
Cargo.lock pin the build inputs. See the [matching and rebuild details](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.6/docs/digital-album-matching.md).

When reporting an issue, include the Trash Amp version, macOS version, music
source type and steps to reproduce. Omit credentials and private server details.
[Report an issue](https://github.com/AberrantWolf/trash-amp/issues).
