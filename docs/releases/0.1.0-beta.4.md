# Trash Amp 0.1.0-beta.4

**Early testing beta. Cross-machine acceptance is in progress. See the
[beta checklist](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.4/docs/release-gates.md)
and the known limits below when testing this build.**

Apple Silicon (arm64), macOS 15 or newer. Intel Macs, Windows, Linux and iOS
are outside this package's supported scope.

## Install

Download `trash-amp-0.1.0-beta.4-macos-arm64.zip` and its `.sha256` file. In the
download directory, verify:

```sh
shasum -a 256 -c trash-amp-0.1.0-beta.4-macos-arm64.zip.sha256
```

Extract the ZIP and move **Trash Amp.app** into Applications.

Tagged release packages require Developer ID signing and Apple notarization,
with the notarization ticket included in the app. Ordinary development artifacts
may still be ad-hoc signed. Separate-Mac first-launch and upgrade acceptance
remain open testing items; see the beta checklist.

## New in beta.4

- Home is the starting point for choosing a local folder or Collector server,
  selecting a library, refreshing its catalog, and opening Lists or Settings.
  Source selectors no longer occupy rows above the browser or tracks. The Home
  icon returns there without losing the current album, selection, search or
  scroll position when returning to the same library. Playback controls remain
  available throughout.
- Familiar actions use compact icons with desktop hover tooltips, accessible
  names, keyboard activation and disabled states. iOS and Android omit hover
  tooltips. Back sits beside the album title; the phone layout leaves more room
  for tracks, including at larger text sizes.
- The iOS development host includes a vendored winit timer backport that avoids
  excessive CoreFoundation timer catch-up after background suspension. The
  preceding hardware check verified foreground resume after three minutes;
  overnight qualification remains open. This ZIP contains only the macOS app.

The iPhone development build has previously been exercised on hardware for signed
install, locked playback, lock-screen seeking and foreground resume. Broader iOS
interruption, accessibility, background-transition and TestFlight qualification
remain open. See the [iOS development notes](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.4/docs/ios-development.md).

## Included

- Album and artist browsing, search, playback queue and macOS media controls.
- Background output-device recovery preserves the queue and playback position.
  Device loss or a default-output change pauses playback; press Play to resume.
  An explicit Play request made while disconnected is retained.
- Filesystem music libraries, including mounted network shares. Each folder
  retains a saved catalog; select a saved folder for offline browsing and use
  **Refresh folder** to rescan. Failed scans preserve the catalog; playback
  still needs available source files.
- Read-only local tags and optional MusicBrainz enrichment. Experimental CUE/BIN
  and single-session, stereo, all-audio redumper playback remain subject to real
  fixture qualification.
- Collector enrollment, browsing, lists, streaming and explicit offline downloads,
  with macOS Keychain credentials and bounded audio/artwork caches. Removed
  connections retain completed downloads for offline playback.
- Automatically trusted private Collector media routes and direct HTTPS media
  through the matching Collector beta.6 shared client. Initial route discovery
  needs the control connection. The server controls public-origin fallback;
  an advertised direct HTTPS endpoint that fails trust/reachability does not
  fall back to the public control origin. Retained downloads work offline.

## Known limits pending qualification

- Physical USB/Bluetooth reconnect and sleep/wake recovery still need native
  qualification. Network, accessibility and large-library/energy acceptance
  remain incomplete.
- WAV, FLAC, MP3, Vorbis and CDDA are the playback validation targets. Captured
  output has not qualified gapless or bit-perfect claims. AAC/M4A gapless, Opus
  and multichannel playback are not advertised as supported.
- Disc support is experimental. Raw mixed-mode/multisession, hidden first-track
  audio controls and de-emphasis are incomplete. PRE flags are reported but
  de-emphasis is not applied.
- Collector automated real-server tests and earlier native FLAC/MP3 journeys
  pass; the broader native interruption, authorization and lifecycle matrix
  remains incomplete. See [Collector connection](https://github.com/AberrantWolf/trash-amp/blob/v0.1.0-beta.4/docs/collector-connection.md).
- Folder scans replace the complete catalog. Incremental scanning, filesystem
  cover art and manual metadata correction remain future work.
